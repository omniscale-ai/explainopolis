# Explainopolis

A map that explains how it was made — built with [metropolis-kit](https://github.com/omniscale-ai/metropolis-kit) and deckcast.

**Open:** https://omniscale-ai.github.io/explainopolis/

- **City / Metro** — the same spec as a 3D city or a metro diagram.
- **🎧 Listen** — a two-voice guided tour (Maya, the guide; Owen, the sceptic); the map moves on every line, and asks you one question you answer with a click.
- **🎙 Ask** — talk to the map: a live voice agent answers from the map's content and points at the evidence (needs a microphone and the network).

This folder is a build output of `examples/explainopolis/` in metropolis-kit; edit the spec there and rebuild.
